# 抉择 · 庭审记录（select）

> 把那件让你辗转难眠的纠结事写下来，由 8 位 AI 陪审员出庭辩论、法官宣判的「选择困难仲裁庭」。

## 项目简介

「抉择 · 庭审记录」是一个帮你做决定的 AI 小工具。你只需要写下一件纠结的事（例如「要不要辞掉体制内工作去创业」），系统会把它自动拆成「去做 / 不做」两个方向，先由正反双方代表（控辩）展开法庭辩论，再由 5 位陪审员各自独立评议，最后由法官写就一份裁定书，给出倾向与置信度。整体采用暗色杂志风的庭审视觉（衬线字体 + 颗粒质感），并附带一本本地「庭审记录册」保存历次裁决。

## 功能特性

- **立案**：写下一件让你纠结的事，系统自动拆成「去做」「不做」两个方向，并从五个维度量化打分。
- **法庭辩论**：正反双方代表（控方 / 辩方）依次陈述理由。
- **陪审团评议**：5 位陪审员各自独立给出意见与倾向（去做 / 不做）。
- **宣判**：法官综合辩论与评议，写就裁定书，给出最终倾向与置信度。
- **庭审记录册**：历次庭审结果保存在浏览器本地，可回看、删除、一键清空。
- **流式输出**：AI 内容以流式（SSE）方式逐步呈现，模拟「合议进行中」的庭审氛围。
- **响应式界面**：移动端自适应，纯前端渲染，无需任何前端框架。
- **AI 能力由后端代理提供**（详见下方「说明 / 备注」）：后端把请求转发到大模型并流式返回。

## 技术栈

- **前端（纯静态）**：`index.html` + `app.min.js`（用 `javascript-obfuscator` 混淆压缩的逻辑）+ 内联 CSS；无前端框架、无构建步骤。
- **后端（可选 / 自托管）**：`server.py`，仅用 Python 标准库 `http.server` 实现 `/api/chat` 反向代理，将请求转发到 Agnes API（`apihub.agnes-ai.com`），密钥通过环境变量 `AGNES_API_KEY` 注入，不进代码。
- **部署**：`Dockerfile`（容器化）+ `render.yaml`（Render / Hugging Face Spaces 部署配置，需设置 `AGNES_API_KEY`、`PYTHON_VERSION`）。

## 本地运行

### 1. 仅预览前端（无 AI）

直接用浏览器打开 `index.html` 即可浏览界面与「庭审记录册」，**此时 AI 庭审功能不可用**，仅能看到静态 UI。

### 2. 完整体验（含 AI 庭审）

AI 能力依赖自托管后端，需自行准备 `AGNES_API_KEY`：

```bash
# 设置大模型密钥（务必替换为自己的 key）
export AGNES_API_KEY="你的_agnes_api_key"

# 启动后端，默认监听 7860 端口
python server.py
```

启动后，让前端通过相对路径 `/api/chat` 访问该后端（将前端与后端同源部署，或在前端中把 API 地址指向你的后端地址），即可获得完整的流式 AI 庭审体验。

### 3. 部署到 Render / HF Spaces

按 `render.yaml` 配置 `AGNES_API_KEY` 后自动部署 `server.py`。注意：该后端**仅作为 API 代理**，不托管静态文件；前端需另行托管并指向后端地址。

## 说明 / 备注

- **AI 密钥安全**：大模型密钥 `AGNES_API_KEY` 通过环境变量注入后端，不写进任何前端 / 代码仓库；前端只与同源 `/api/chat` 通信，不会直接暴露密钥。
- **为何演示页 AI 不可用**：GitHub Pages 只能托管静态文件，无法运行 Python 后端。要获得完整 AI 体验，请按「本地运行」自托管 `server.py`，并把前端指向你的后端地址。
- **隐私**：所有庭审记录（你的纠结事与裁决）仅保存在**浏览器本地**（记录册），不上传任何服务器；清理浏览器数据会一并清除。
- **定位**：本工具由 AI 生成内容，仅供自省与参考，**不具任何法律效力**。
